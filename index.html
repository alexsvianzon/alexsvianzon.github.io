Median Drift Sort Algorithm

Median Drift Sort is a sorting algorithm that sorts an array by checking each element with the median of the list, swapping it before or after the median if necessary, and repating this on two smaller lists, split by the median, until the list is fully sorted. You can learn more about it and see the implementation on my GitHub repository linked above.
